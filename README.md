# 2G Store (noboolean Umbrel community app store)

Add in Umbrel: App Store -> ... -> Community App Stores -> paste `https://github.com/noboolean/umbrel-community-app-store`

Apps:
- `noboolean-pironman5` - SunFounder Pironman 5 with a fixed dashboard (source: https://github.com/noboolean/pm_dashboard_www, branch main) and custom OLED pages.

The dashboard build in `noboolean-pironman5/custom-www` is produced by `npm run build` in pm_dashboard_www.
`backup/` holds a secret-free copy of the previous sunfounder-pironman5 install config.
